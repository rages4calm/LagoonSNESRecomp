## Reproduction

Generated code and ROM-derived fixtures remain local. With the pinned owned ROM
and matching generated tree, the new public oracle can be run from the repo:

```powershell
python -P tools/test_boss_animation_oracle.py --rom "..\Lagoon (USA).sfc" --gen src/gen --out "<fresh scratch output>"
```

Local portable inputs use explicit `--exe`, `--manifest` and fresh `--out`:

- `validation/inputs/batch25/native/run.py`: original Green/Red routes by default;
  `--watch` selects the six affected encounter routes. `--compare` accepts fresh
  matched controls; `--dry-run` validates immutable dependencies without launching.
- `validation/inputs/batch25/actors/run.py`: `--room 2c`, `2f` or `35`, and
  `--mode off`/`auto` for the actual-spawn far-enemy routes.
- Existing batch24 renderer inputs cover the twelve room loaders and original
  four-family door chain. The original registry and immutable seeds are reused;
  no new fixture states are required.

Private validation receipts retain hashes and bounded summaries, not public ROMs,
generated source, states, audio or raw replay dumps. Retired historical executable
paths are not rerunnable controls; later changes need fresh matched controls.
