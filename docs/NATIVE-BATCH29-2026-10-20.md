sources, use separate small output directories:

```powershell
python -P tools/test_endgame_tail.py --rom <ROM> --out <scratch>/guards
python -P tools/test_endgame_inline_oracle.py --rom <ROM> --out <scratch>/inline
python -P tools/test_endgame_windows_oracle.py --rom <ROM> --gen src/gen --out <scratch>/windows
python -P tools/test_credits_oracle.py --rom <ROM> --gen src/gen --out <scratch>/credits
```

`validation/inputs/batch29/native/run_endgame.py` from the workspace root. Supply
explicit `--exe`, `--manifest` and a fresh `--out`; `--dry-run` checks immutable
dependencies without writing or launching. `--compare <fresh-control>` retains
the strict full-presentation result, including intentional renderer differences.

generated bodies, seed states and private runtime captures are not public source.
