# Lagoon Recomp 0.2.5

Fixes broken-looking text in the exploration map. The 640x520 map was fitted
into a 448-pixel-high intermediate buffer, dropping rows from the bitmap font.
The frozen presenter now allocates enough resolution for title-owned panels
while preserving the game viewport aspect. Map geometry, discovery, saves and
gameplay are unchanged. Save-state browser and rewind retain their existing
presentation path. The interpreter safety net remains enabled.

Checked on the actual hidden OpenGL presenter with Enhanced graphics at 1080p,
using 4:3, 16:9 and 32:9 settings. Map open/close and guest resumption pass.
These are focused assisted scene checks, not a new campaign or physical controller
certification. The owner's completed campaign remains the release baseline.

optional X68000 soundtrack are included. Bring your own clean USA ROM.
